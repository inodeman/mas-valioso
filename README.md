## Cómo subirlo

### YouTube Shorts
1. Descarga el MP4 de YouTube del short que quieras.
2. YouTube Studio → **Crear** → **Subir videos**.
3. Pega el título (primera línea) y la descripción del archivo `copy/*-youtube.txt`.
4. Marca que es un Short (vertical). Publica entre 18:00 y 21:00.

### TikTok
1. Descarga el MP4 de TikTok.
2. TikTok → **+** → subir (no recortes).
3. Pega el texto de `copy/*-tiktok.txt`.
4. Publica.

## Player en GitHub Pages

Si quieres el player en `https://inodeman.github.io/mas-valioso/`:

1. Repo **Settings → Pages**
2. Source: **GitHub Actions**
3. Re-run the *Deploy GitHub Pages* workflow
