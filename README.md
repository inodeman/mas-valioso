El video es el mismo corte (9.00s, 720×1280, texto quemado). Cambia el caption y el título por plataforma.

## Cómo subirlo

### YouTube Shorts
1. Descarga `mas-valioso-youtube-shorts.mp4`.
2. YouTube Studio → **Crear** → **Subir videos**.
3. Pega el título y la descripción de `copy/youtube.txt`.
4. Marca que es un Short (vertical). Publica entre 18:00 y 21:00.

### TikTok
1. Descarga `mas-valioso-tiktok.mp4`.
2. TikTok → **+** → subir (no recortes).
3. Pega el texto de `copy/tiktok.txt`.
4. Publica. El texto ya va en el video; no hace falta sticker extra.

## Player en GitHub Pages

Si quieres el player en `https://inodeman.github.io/mas-valioso/`:

1. Repo **Settings → Pages**
2. Source: **GitHub Actions**
3. Re-run the *Deploy GitHub Pages* workflow

## Arco

- **0–3s** Gancho — *En 3 segundos serás el ser más rico del mundo. ¿Listo?*
- **3–6s** Giro — todo el dinero hoy, morir mañana.
- **6–9s** Golpe — no lo aceptarías. Tu vida vale más. Da gracias a Dios.
